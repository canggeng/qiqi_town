# 淇淇的小镇 · 项目宪法

本文件定义项目的不可妥协原则。所有规格、实现和验收均以此为准。

## 1. 玩家体验优先

- 这是一个温柔、无失败、面向儿童与家庭的 3D 小镇生活游戏。
- 不使用战斗、死亡、倒计时惩罚、体力条或会让玩家卡死的设计。
- 每天有 1 个主线 + 3 个可选小游戏，其余时间自由探索。
- 对话与事件选择必须有温和、可理解的结果，不锁死主线。

## 2. 鼠标全流程可用

- 从标题到结局，所有操作必须能用鼠标完成。
- 键盘快捷键只能作为附加便利，不能成为必需。
- 点击地面移动、右键转镜头、滚轮缩放；点击人物/物件交互。

## 3. 数据与表现分离

- 存档只序列化 `GameState`，绝不序列化 Panda3D 节点。
- 剧情、对话、事件、小游戏配置尽量放在 `data/` 或 `specs/` 可读文件中。
- 逻辑模块（存档、导航、时间、条件求值）必须可以在没有图形窗口的情况下单元测试。

## 4. 项目隔离

- 使用 uv 与项目内 `.venv`，不执行全局 pip 安装。
- 运行时不联网，不依赖外部服务。
- 所有资源路径通过 `qiqi_town.paths` 解析，兼容开发态与 PyInstaller。

## 5. 可交付

- 每个里程碑都必须能启动、能截图、能通过冒烟测试。
- 最终交付为 Windows 免安装文件夹 + `QiqiTown.exe`，在无 Python 环境下可运行。
- 音频、字体、参考图必须有清晰的授权/使用记录。

## 6. 可维护

- 新增剧情优先改数据，不把对话写死在 UI 代码里。
- 新系统必须有至少一个自动测试，或明确在 `tasks.md` 中登记手动验收项。
- 不在未验证的情况下引入大型框架；运行时依赖保持在 Panda3D + 标准库。

## 7. 角色一致性

- 淇淇的轮廓、服装、配色以 `docs/reference/` 中的用户参考图为准：黑色齐刘海短发、奶白蕾丝头巾、白色无袖连衣裙、红色大气球。
- 游戏内为原创柔和低多边形 3D 演绎，不直接打包带水印的参考图。
